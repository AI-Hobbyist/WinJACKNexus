本轮验证：在现有 `build` 目录完成所需目标的 Release 编译。首次编译因测试缺少 `QGraphicsItem` 头失败，补头后通过。实窗失败诊断显示适配器选区在测试主动移走焦点时已清除，重新建立语言操作前的明确选区后通过；重命名测试也增加实窗获得焦点的前置检查。设备菜单重建时 Qt 子菜单对象仍存活，修复为先删除拥有的旧子菜单再重建，防止旧文字和回调残留。
