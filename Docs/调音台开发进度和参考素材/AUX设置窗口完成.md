# AUX 设置窗口完成

日期：2026-09-22

状态：参考界面、共享状态与模拟交互已完成

## 完成范围

依据参考图完成独立 AUX 设置窗口，并与主调音台动态 AUX 通道同步。窗口延续蓝黑色视觉语言，包含 AUX 列表、顶部工具栏、空间声像器、参数设置和分声道发送强度五个区域。

当前阶段使用动态模拟电平验证界面刷新与交互；真实音频路由、DSP 增益和会话持久化不属于本次参考界面范围。

## AUX 列表与动态同步

- 左侧列表显示 AUX 编号、名称、启用状态、总发送旋钮、Pre/Post 状态和设置入口。
- 默认提供 8 个独立示例 AUX，覆盖单声道、立体声、5.1 和 7.1 的源/目标组合。
- 支持动态新增和删除 AUX，至少保留一个 AUX。
- 新增 AUX 后自动选中并滚动到列表底部；删除后自动修正滚动范围。
- 主调音台中的 AUX 名称、来源、编号和通道数量由共享状态动态生成。
- AUX 增删后主调音台立即重建 AUX 通道，Master 始终固定在最右侧。
- 列表提供常驻垂直滚动条；内容溢出后滑块按可见区域比例缩放。
- 支持鼠标滚轮、拖动滑块和点击轨道滚动列表。

## 总发送旋钮

- 列表发送量使用完整旋钮组件，包含背景刻度弧、动态高亮弧、实体旋钮盘和位置指示线。
- 按住旋钮上下拖动可调整当前源发往目标 AUX 的整体发送强度，范围为 `-72~+12 dB`。
- 多声道发送整体调整时保留各分声道原有相对电平差。
- 发送到自身的 AUX 保持禁用，旋钮不可调节。

## 声道布局

- 源布局和目标布局可分别选择单声道、立体声、5.1 和 7.1，并可组成任意组合。
- 源布局决定分声道发送条数量和标签，目标布局决定空间声像器参考点数量和位置。
- 每个 AUX 独立保存源布局、目标布局、点位、发送强度和空间参数。
- 修改目标布局不会重置源发送强度；修改源布局会按新通道数重建发送通道。

## 每个源通道独立设置

- Input 通道和 AUX 通道的 AUX 齿轮均可打开设置窗口，FX 齿轮保留给独立 FX 设置。
- Input 使用 `input:<通道编号>` 作为源键，AUX 使用 `aux:<AUX ID>` 作为源键。
- 每个源通道独立保存各目标 AUX 的启用、Pre/Post、布局、点位、Link、宽度、角度、覆盖范围和分声道发送强度。
- 新增或删除 AUX 时，目标会同步到所有已创建的源通道上下文。
- AUX 通道发往自身时由模型标记为自身路由，强制关闭并禁止重新启用，避免回环。
- 窗口标题和列表标题显示当前源通道名称，便于区分编辑上下文。

## 空间声像器

- 绘制同心圆、方位射线和角度标记；源声道使用实心可调点，目标声道使用半透明参考点。
- 可调点可在圆形范围内拖动，超出圆周时自动限制在边界内。
- 立体声源默认启用点位 Link；拖动任一点时保持两点相对位置并整体移动。
- 两点间 Link 线和参数区宽度滑杆共享宽度状态，角度滑杆旋转全部可调点。
- 每个可调点独立保存 `5°~360°` 覆盖范围，并绘制随范围变化的可延展外圈。
- 当前点具有高亮描边、半透明高亮环、亮色外圈和外圈拖拽手柄。
- 点击实心点可选中并拖动位置；拖动外圈或在点/外圈上滚轮可调整当前点覆盖范围。
- 参数区覆盖范围滑杆控制当前选中点，指向性扇区同步使用该点覆盖范围。
- 显示指向性图开关控制半透明覆盖扇区，重置按钮恢复默认空间参数和发送强度。

## 分声道发送

- 分声道发送表示各源声道发往当前 AUX 的发送强度，不是 AUX 输出声道音量。
- 通道条数量根据源布局为 1、2、6 或 8 条。
- 每条包含声道名称、dB 数值、发送推子、独立电平表、Mute 和 Solo。
- 推子及电平表范围为 `-72~+12 dB`，底端显示 `−∞ dB`。
- 电平表使用绿、黄、红三段表示普通、接近 0 dB 和超过 0 dB 的电平。
- 推子滑块具有中央水平刻线，所有通道卡片与标题使用统一配色。

### Link / Split

- 标题栏提供 `Link` / `Split` 模式，按每个源通道的每个目标 AUX 独立保存。
- Link 模式下，拖动任一推子会按相同 dB 增量调整整组发送，保持相对差值并在边界分别钳制。
- Split 模式下，仅调整当前分声道。
- 分声道 Link/Split 与空间声像器点位 Link 使用独立状态，互不影响。
- 拖动开始时缓存整组发送值，后续移动基于快照计算，避免连续事件造成相对值漂移。

## 窗口缩放

- 窗口使用统一比例等比缩放 `1360 × 768` 设计画布，并将内容居中显示。
- 绘制区域与鼠标命中区域共用同一坐标变换。
- 拖动改变窗口宽高比时，圆形、旋钮、推子、按钮、文字和滚动条不会被非等比拉伸。

## 代码结构

- `src/common/include/WinJACKNexus/Common/AuxMixerState.hpp`：布局枚举、总线、发送通道、每源状态和公共接口。
- `src/common/src/AuxMixerState.cpp`：默认数据、布局重建、增删同步、源状态隔离和自身路由保护。
- `src/ui/include/WinJACKNexus/UI/AuxSettingsWindow.hpp`：AUX 设置窗口公共接口。
- `src/ui/src/AuxSettingsWindow.cpp`：窗口自绘、列表、滚动条、声像器、旋钮、推子和鼠标交互。
- `src/ui/src/MixerWindow.cpp`：共享 AUX 状态、动态通道生成和设置窗口入口。
- 非 UI 状态位于 `common`，自绘与交互代码位于 `ui`。
