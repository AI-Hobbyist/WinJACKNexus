# 调音台主界面完成

日期：2026-09-22

状态：已完成

## 完成范围

依据 `参考素材/Main.png` 完成调音台主界面的布局、视觉风格、动态模拟数据和临时交互。主界面现已作为后续混音逻辑、音频数据和设置界面的 UI 基础，不再继续拆分主界面设计阶段文档。

## 界面结构

- 主界面分为 Inputs、AUX Sends 和 Main Output 三个通道组。
- 当前模拟数据包含 8 个 Input、6 个 AUX 和 1 个 Master。
- 通道数据使用动态容器，为后续增加任意数量的 Input 和 AUX 保留扩展能力。
- 通道固定宽度为 104 px，不随窗口宽度变化。
- Master 始终固定在窗口最右侧，不参与横向滚动和 Input/AUX 比例分配。
- Master 左侧区域由 Input 和 AUX 两个独立视口组成，初始比例为 3:2。
- Input 与 AUX 之间的分界支持鼠标拖动，可自由调整相对宽度。
- Input 与 AUX 最窄均保留一个 104 px 通道宽度，避免区域完全收起。
- 分界具有可见握柄，鼠标悬停时显示水平调整光标。
- Input 与 AUX 分组卡片始终铺满各自视口，分组标题按视口宽度保持居中。
- 窗口最小尺寸为 760 x 560，默认尺寸为 1024 x 768。
- 通道卡片、表头、电平表、按钮组、推子和文字尺寸根据窗口高度重新计算。

## 滚动与命中

- Input 和 AUX 分别拥有独立的绘制视口、滚动偏移和鼠标命中范围。
- 两个视口底部均显示横向滚动条。
- 滚动条滑块宽度按可见区域与内容宽度比例计算。
- 两个滚动条均支持拖动滑块、点击轨道定位和区域内鼠标滚轮操作。
- Input 与 AUX 的滚动互不影响，Master 不参与滚动。
- 通道绘制、组边界、按钮命中和推子拖动统一使用所属视口的坐标。

## 通道内容与交互

- 每个通道显示名称、来源、单柱总体电平、AUX、FX、SEL、M、S、设置入口、推子、dB 值和通道编号。
- 每个通道仅显示一条总体电平值，不拆分左右声道。
- 点击电平表或其模式标签，可在输入电平 `IN` 和推子后电平 `POST` 之间切换。
- 每个通道独立保存电平表显示模式，切换一个通道不会影响其他通道。
- AUX、FX、静音和独奏按钮在模拟阶段支持独立开关显示。
- 推子支持鼠标拖动，按钮区域与推子命中区域相互独立。
- Master FX 行采用左右并排布局，左侧为 FX，右侧为独立设置入口。
- 点击 Master 设置入口不会切换 FX 状态。
- SEL 和设置入口目前保留为界面入口，具体面板将在后续逻辑阶段接入。

## 推子规格

- 推子顶部最大值为 `+12.0 dB`。
- 推子从顶部至 95% 位置连续映射为 `+12.0~-72.0 dB`。
- 推子到达最底端时显示 `−∞`。
- 正 dB 值显示 `+` 前缀。
- Input 推子统一使用中性灰色。
- AUX 推子统一使用蓝色。
- Master 推子统一使用红色。
- 通道标签仍可保留各自强调色，推子配色与标签强调色相互独立。

## 电平表规格

- 电平表和推子轨道高度统一为通道卡片高度的 23%。
- 显示范围为 `-72 dB` 至 `+12 dB`。
- 输入电平模式直接显示当前输入电平。
- 推子后电平模式在输入电平基础上叠加当前推子增益，并限制在 `-72~+12 dB` 显示范围内。
- 推子位于 `−∞` 时，推子后电平显示在 `-72 dB` 底限。
- 电平表上方显示 `IN` 或 `POST` 标签以标识当前模式，标签与电平表均可点击。
- 刻度为 `+12`、`0`、`-12`、`-24`、`-36`、`-48`、`-60`、`-72`。
- 电平颜色使用三个纯色区段：
  - 绿色：`-72 dB` 至 `-12 dB`
  - 黄色：`-12 dB` 至 `0 dB`
  - 红色：`0 dB` 至 `+12 dB`
- 未激活区段保留低透明度底色，当前电平以内使用纯色填充。
- 动态模拟电平以 55 ms 周期平滑变化，目标范围允许超过 `0 dB`，便于检查红色区段。
- 真实逻辑接入后，电平值应限制在当前显示范围；`0 dB` 以上的显示余量不代表允许 DSP 输出削波。

## 文字与视觉

- 延续深色蓝黑背景，以及蓝色 Input、紫色 AUX、绿色 Main Output 分组视觉。
- 分组标题、通道名称和来源文字根据实际字体度量自适应缩小。
- 自适应同时考虑可用宽度和高度，避免固定通道宽度或视口缩放时发生裁切。
- 分组标题位置由视口决定，不随内部通道滚动位置或内容总宽度变化。

## 入口与模块结构

- 快捷栏包含固定“调音台”入口。
- 主程序从可执行文件同级目录加载 `mod_mixer.dll`，并通过标准 NodeApi 创建调音台窗口。
- `src/ui/include/WinJACKNexus/UI/MixerWindow.hpp`：调音台窗口公共接口。
- `src/ui/src/MixerWindow.cpp`：调音台自绘、响应式布局、模拟数据和临时交互。
- `src/mixer/Library.cpp`：调音台节点模块生命周期和窗口创建入口。
- `src/mixer/CMakeLists.txt`：`mod_mixer.dll` 构建定义。
- `src/ui/src/TrayController.cpp`：快捷栏调音台按钮及 QAction 绑定。
- `src/app/main.cpp`：同级 DLL 加载、节点初始化和入口触发逻辑。
- 调音台界面实现位于 UI 公用库，界面变更实际更新 `build/bin/ui.dll`；`mod_mixer.dll` 通过该库使用界面实现。

## 后续逻辑接口

当前 `MixerWindow.cpp` 内部的 `Channel` 结构仅承载界面模拟状态，包括名称、来源、编号、标签强调色、推子位置、电平目标值、电平显示模式及 AUX、FX、静音、独奏状态。接入真实逻辑时应：

1. 将模拟通道列表替换为混音引擎或会话模型提供的动态通道快照。
2. 将模拟计时器替换为真实总体峰值或 RMS 数据刷新源。
3. 分别提供真实输入电平和推子后电平，或由统一增益模型计算推子后读数。
4. 将推子拖动映射为真实增益命令，并由模型状态回写位置。
5. 将 AUX、FX、静音和独奏按钮连接到对应混音命令。
6. 为 SEL 和设置入口接入通道详情、效果器或路由配置界面。
7. 保留 UI 层中的自绘与布局计算；可复用的非 UI 模型放入 `src/common`。
8. 如需显示削波状态，应在真实逻辑中单独锁存，不与当前瞬时电平填充混用。
