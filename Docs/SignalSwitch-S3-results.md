# Signal Switch S3 完成记录

2026-10-20，Release。工程接入和基本编辑器已实现；S4 的锁定桌面展示、布局编辑及穿透操作尚未实现，快捷栏对应命令暂禁用，打开编辑器入口可用。

主模块位于 EXE 同级；五个节点部署到正式扫描目录 `nodes/signal_switch/{mono,stereo,5_1,7_1,midi}`。节点 settings 持久化 switchId、显示名称和通断，宿主通过稳定身份同步图中别名；工程主状态经 Base64 保存到 signalSwitchStateBase64，恢复节点期间先关闭处理，关系恢复完成后发布最终状态。

按用户最新要求，五种新建节点默认启用。离线模块测试已验证五种版本无需控制命令即可直通，以及恢复工程已保存关闭状态不会被新默认值覆盖。结果见 `SignalSwitch-S3-module-tests.log`。

在现有 build 目录构建 wjn_signal_switch_host_tests 的 Release 目标及必要依赖；最终退出码 0。测试使用 Windows 平台、100% 缩放、系统字体及可见真实窗口，35 项检查通过，累计 4 次窗口显示。结果见 `SignalSwitch-S3-host-tests.log`；实际 HWND 屏幕截图为 `SignalSwitch/S3/editor.png`，已检查按钮文字及 CJK 显示。

实窗检查覆盖正式节点库发现五个双模式无 GUI DLL、生产宿主的 VIRT 创建/准备、公共按钮、一节点一按钮、通断和工程脏标记、图及按钮命令的双向改名、工程 Base64 保存恢复、编辑器大小位置和按钮预设、关闭重开、快捷栏绑定、i18n 热切换及删除节点清理。第一次测试因测试子图未配置正式可见节点集合而在改名项失败，修正测试设置，并补充图刷新时的名称保留后重跑相关实窗验证通过。

测试不依赖运行中的 JACK 服务。真实 JACK 信号链、真实 MIDI 接收端及完整根子图音频调度不属于本次实窗结果的证明范围；锁定展示及穿透由 S4 验证。人工审校和人工安装验收已跳过（用户指令），跳过不代表通过。构建中既有 Node/Native Fx i18n 声明的 C4273 警告未在本功能中扩张处理。
