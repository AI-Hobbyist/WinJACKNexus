# WinJACKNexus

[简体中文](README.md) · [日本語](README.ja.md) · [English](README.en.md) · [한국어](README.ko.md)

Windows x64 向けのモジュール式オーディオ・MIDI ルーティングアプリです。グラフィカルなパッチベイで JACK ポートを接続し、デバイス、ミキサー、ネイティブエフェクト、VST ホスト、サブグラフを組み合わせて処理チェーンを作成できます。

## 現在の機能

| 機能 | 内容 |
| --- | --- |
| パッチベイ | オーディオ/MIDI の接続、プロジェクトの保存と復元、サブグラフ |
| デバイスノード | WASAPI 入出力、システム MIDI 入出力 |
| ミキサー | デジタルミキサー、8/16/24 チャンネルの Classic Mixer |
| Native Fx | Gate、31 バンド Graphic EQ、De-Esser、Compressor、Limiter、Delay、Parametric EQ、Reverb |
| メーターブリッジ | マルチチャンネル表示、履歴グラフ、CSV 記録 |
| VST ホスト | VST3。ローカルビルドでは別途 SDK を用意すれば VST2 にも対応 |
| MIDI Tools | チャンネル分割、16×16 マトリクス、SF2/SFZ 音源読み込み |
| コントロールデッキ | 信号スイッチ、効果音ボタン、モノラルピークメーター、マルチチャンネルゲインノブ |
| 外観と言語 | テーマトークン、カスタムテーマ、中国語・日本語・英語・韓国語 |

## コントロールデッキ

すべてのバージョンがメイングラフとサブグラフに対応し、それぞれ独立した DLL です。ノード自体には GUI がなく、クイックアクセスバーからコントロールデッキを開いて操作します。

| コントロール | バージョンと動作 |
| --- | --- |
| 信号スイッチ | モノラル、ステレオ、5.1、7.1、MIDI。新規作成時はオンで信号を通過 |
| 効果音ボタン | ステレオ出力のみ。クリックまたはグローバルショートカットで一度再生し、再トリガーで先頭から再生 |
| ピークメーター | モノラル入力のみ（出力ポートなし）、−72～+12 dBFS。右クリックで横向き・縦向きを切り替え |
| ゲインノブ | モノラル、ステレオ、5.1、7.1。1 個のノブでノードの全チャンネルを制御し、dB 範囲を変更可能 |

- エディターでドラッグして配置します。Ctrl または範囲選択で複数選び、右クリックメニューでサイズ、色、グループ、自由配置・グリッド整列を設定できます。グループ名は変更でき、まとめて移動できます。信号スイッチは排他または独立動作に設定できます。
- 名前はグラフのノード名と同期します。色は既定でテーマを継承し、個別指定も可能です。
- レイアウトをロックするとエディター背景が隠れ、配置済みコントロールを同じ位置のまま通常のアプリウィンドウより前に表示します。クイックアクセスのメニューからロック、解除、マウス透過、エディター表示を操作できます。
- 「コントロールの不透明度」はコントロールのみに適用します。マウス透過中は Alt+左クリックで操作でき、ゲインノブでは数値入力が開きます。
- 効果音ボタンの右クリックからファイルとグローバルショートカットを設定できます。他のアプリが前面でも動作し、競合時は以前の設定を維持します。対応形式は BASS/BASSmix と導入済みの互換デコーダーによります。WAV、AIFF、MP3、OGG、MOD を検証済みです。追加の x64 BASS デコーダー DLL は `control_deck/bass_plugins/` に置いて再起動してください。
- 配置、ウィンドウのサイズと位置、グループ、関係、色、寸法、不透明度、マウス透過、ノード設定はプロジェクトに Base64 で保存します。効果音のパスとショートカットも保存しますが、音声ファイルは外部のままです。プロジェクトを開いても自動再生しません。

すべてのコントロールノードを `Control Deck` に分類し、`nodes/control_deck/` に配置します。`control_deck.dll` は実行ファイルと同じ場所、パネルの翻訳はアプリ本体の `locate/` に統合しました。旧プロジェクトの `nodes/signal_switch/` は導入済みの新ディレクトリに自動対応し、ノード DLL 名と保存 ID は維持します。ピークメーターには測定信号を分岐して入力し、信号チェーンに直列接続しないでください。

## ミキサーウィンドウ

デジタルミキサーの「チャンネル一覧」と「チャンネル詳細」は独立したトップレベルウィンドウで、それぞれタスクバーのサムネイルを持ちます。単独で前面に表示でき、メインミキサーを最小化しても一緒に最小化されません。

「チャンネル詳細」でチャンネル（「モニター」を含む）を切り替えると、「チャンネル一覧」のハイライトとメインミキサーのスクロール位置が同期します。一覧でチャンネルを選ぶとその詳細が開き、同じようにメインミキサーも同期します。

## ダウンロードと起動

Windows x64、JACK2、Microsoft Visual C++ ランタイムが必要です。フォルダー構成を保って展開し、`WinJACKNexus.exe` を起動してください。実機に接続する前に JACK の設定と配線を確認してください。

起動時にまず利用可能な JACK サーバーを確認します。見つからない場合、「JACK サーバー設定」の自動起動が有効ならその設定で起動を試み、それでも準備ができなければモーダルの「JACK サーバー設定」ウィンドウを表示します。サーバーの準備が整うとこのウィンドウは自動的に閉じ、起動を続行します。ウィンドウを直接閉じるとアプリは終了します。

「全体設定 → Windows プロセスの優先度」では、低、通常以下、通常、通常以上、高、リアルタイムの 6 段階から選べます。変更はこのアプリに直ちに適用され、以後起動する子プロセス（jackd、VST ホストプロセス、VST スキャナー）にも使われます。すでに実行中の子プロセスは元の優先度のままです。リアルタイムはシステム全体の応答に影響する可能性があり、追加の Windows 権限が必要です。Windows が拒否した場合は元の優先度に戻し、失敗を通知します。

GitHub の **Actions → Build full Release package → Run workflow** から Release 全体を手動ビルドできます。成功後に `WinJACKNexus-Release-x64-VST3` アーティファクトをダウンロードしてください。完全版アプリの ZIP、SHA256、Qt ランタイム、現在の全モジュール、および `prerequisites/` 内の JACK2 と VC++ x64/x86 インストーラーを含みます。先にこれらの依存ランタイムをインストールしてください。この Action は VST2 を無効にし、VST3 を有効にします。初回のクラウドビルド結果は Actions 上で確認してください。

差分更新パッケージには対応する既存バージョンが必要です。都合のよい時にアプリを終了し、バックアップして上書き・再起動してください。音声処理中に DLL を置き換えないでください。差分更新と完全版は異なります。

## 完了状況と予告

コントロールデッキのスイッチ、効果音、ピークメーター、4 種類のゲインノブ、配置操作、プロジェクト復元は実装済みです。Release ビルド、オフライン処理、Windows 実ウィンドウの自動検証を通過し、他プロセスが前面の場合の効果音ショートカットと四言語表示も確認しています。実デバイス、実際の JACK 接続、インストール、手動受け入れ確認は未検証です。

起動前の JACK サーバー確認、プロセスの優先度設定、「チャンネル一覧」「チャンネル詳細」の独立したタスクバー表示と連動動作を実装しました。

**予告：** DAW Bridge、Carla 連携、未完成のメインセッション音声デバイス管理フローは計画・開発段階です。現在提供済みの機能には含みません。
