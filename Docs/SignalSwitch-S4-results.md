# Signal Switch S4 完成记录

2026-10-20，Release。已实现右键管理、多选、宽高与颜色、主题继承、独立和互斥关系、布局分组及组名修改、整组拖动、自由与网格对齐、锁定展示、按钮透明度、鼠标穿透和 Alt＋左键。

锁定时隐藏编辑器和分组底板，将公共按钮原位放入各自的透明置顶窗口；保留锁定前屏幕坐标、尺寸和排列。按钮之间没有覆盖下层应用的整块背景窗口。解锁或打开编辑器后返回同一份布局。透明度只作用公共按钮，编辑器和原生菜单维持正常不透明度。

穿透通过 Windows 窗口样式实现，Alt＋左键由有生命周期管理的低级鼠标钩子识别并拦截该次点击，再排队到 GUI 线程提交通断命令；钩子不接触音频线程。不能安装钩子时关闭穿透并保留可直接点击的按钮。刷新及状态同步使用应用统一 FPS。

现有 build 目录 Release 构建通过；状态测试 13 项通过。Windows 平台、100% 缩放、系统字体的布局实窗测试最终通过 58 项检查，22 次窗口显示，见 `SignalSwitch-S4-layout-tests.log`。包含失败及必要重跑的本批累计约 80 次显示，低于 100 次；测试生成的窗口及独立下层进程均已关闭。

测试用独立进程创建真实下层窗口，并确认其 HWND 是系统前台窗口。原生 SendInput 验证普通点击透传、Alt＋左键只切换按钮且不落到下层、按钮间空白不拦截点击。还验证了公共控件、批量尺寸、互斥冲突显式选择、分组改名、整组拖动不误触、网格锚点和相对偏移、独立颜色与恢复继承、按钮透明度、锁定原位和真实 TOPMOST 样式、快捷栏返回编辑器、Base64 状态保存。实桌面合成截图见 `SignalSwitch/S4/overlays.png`，已检查仅按钮悬浮于下层测试窗口之上。

验证修复了 QColor 空花括号赋值未清除实例颜色的问题。一次重跑受到 Windows 前台激活限制影响，测试改用独立窗口的真实标题栏点击激活，不修改生产窗口行为、不跳过前台断言；最终原生输入断言全部通过。

未验证物理多显示器移除场景，记录 MANUAL/PENDING；没有运行额外 DPI 矩阵。人工审校和安装验收已跳过（用户指令），跳过不代表通过。未运行 JACK 服务连接测试，未停止用户应用或音频进程。
