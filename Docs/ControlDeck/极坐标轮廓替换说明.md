# 极坐标填充能量轮廓增量包

本包适用于已安装 Control Deck 分析表盘功能的 Windows x64 Release 版本。

1. 保存工程，正常退出 WinJACKNexus 后备份同名文件。
2. 将包内 `ui.dll`、`control_deck.dll` 和 `nodes/` 语言文件按相对路径覆盖到程序目录。不要在音频运行时替换 DLL。
3. 在极坐标组件的右键“显示模式”中选择“填充能量轮廓”。原“声道射线”保持默认，旧工程行为不变。

单声道、立体声、5.1 和 7.1 均支持。空间轮廓复用 common/MixerPolarCurve 的功率插值与时间平滑；半径范围 −72 至 +12 dBFS，虚线环为 0 dBFS，不按当前最大值归一化。

5.1/7.1 的 LFE 显示为中心的独立颜色强度圈，半径按自身 RMS 变化，不参与空间轮廓插值。LFE 静音时圆圈收至中心，保留 LFE 标记。

全局主题 Token：`analysis-polar-stroke`、`analysis-polar-fill`（支持透明度）、`analysis-polar-lfe-stroke`。模式沿用 JSON 的 `analysisOverlay` 字段保存；极坐标中 true 为填充轮廓，缺省 false 为射线。

已完成必要 Release 构建与 24 个布局的离线真实模块/Windows 实窗回归，含右键切换、状态保存恢复、旧工程缺省、透明填充、LFE 主题改色与静音收缩。最终日志 `build/control-deck-polar-contour-final-{build,tests}.log`。人工安装、现场 JACK/听音验收按用户指令跳过，不记 PASS。没有自动覆盖安装目录或启动/停止用户应用。

本包不是完整安装包；无需替换未列入 manifest 的节点模块或 common.dll。保留已有目录结构。归档清单、逐文件 SHA-256 和源码检查点见 manifest.json。
