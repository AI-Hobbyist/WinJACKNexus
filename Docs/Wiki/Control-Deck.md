# Control Deck

Control Deck 是节点的统一控制面板：把信号开关、音效按钮、峰值表、增益旋钮、分析表盘和响度表组放到一块可编辑的面板里，集中操作。

## 节点类型

| 控件 | 版本 |
| --- | --- |
| 信号开关（Signal Switch） | 单声道、立体声、5.1、7.1、MIDI |
| 音效按钮 | 立体声 |
| 峰值电平表 | 单声道、立体声、5.1、7.1 |
| 示波器、声谱图、极坐标图、频谱直方图、频谱曲线图 | 各有单声道、立体声、5.1、7.1 |
| 响度表组 | 单声道、立体声、5.1、7.1，显示整体标准值 |
| 增益旋钮 | 单声道、立体声、5.1、7.1 |

节点本身没有 GUI。在接线盘添加 Control Deck 节点后，控制面板中会自动出现对应控件。节点库按 Routing、Playback、Gain、Meters、Analysis 分层，运行文件也按功能放在 `nodes/control_deck/` 子目录。旧 `nodes/signal_switch/` 和旧平铺 Control Deck 路径自动映射到新目录；旧 DLL 不重复列出。显式保存工程后记录新路径。

## 打开编辑器

快捷栏的「控制面板」下拉菜单 →「打开编辑器」。空白处右键也可以「关闭编辑器」。

## 布局编辑

- 拖动控件排列；框选或按 Ctrl 多选。
- 右键控件可设置宽度和高度、按钮颜色、继承主题颜色、创建分组。互斥/独立关系只在信号开关按钮右键菜单显示；其他组件和混合选择隐藏。
- 空白处右键：锁定布局、网格对齐、网格间距、控件透明度、鼠标穿透、关闭编辑器。
- 分组卡片可以改名并整体拖动；也可以选择组内按钮或取消分组。
- 控件名称跟随图中节点名，颜色默认继承主题。

## 锁定与穿透

- 「锁定布局」会隐藏编辑背景，把控件按当前位置置顶显示在普通应用窗口前。
- 「鼠标穿透」只在锁定状态可用；启用后用 Alt+左键操作控件。
- 「控件透明度」只影响控件本身。

## 信号开关

- 每个开关节点对应面板上的一个按钮，新建时默认「开启」。
- 左键切换通断；右键可以开启/关闭、重命名、改尺寸与颜色、设置互斥、创建或移入分组。
- 端口按版本为 1、2、6、8 个音频通道或 1 个 MIDI 通道，`IN_*` 到 `OUT_*` 同序号直通；关闭时输出静音（写零）。
- MIDI 开关关闭时会清理已透传的音符和延音，重新打开不会重放。
- 互斥组里的开关一次只能开启一个；切换时先关旧再开新，允许短暂全关。

## 音效按钮

- 右键「载入音效…」选择文件，或「全局快捷键…」设置快捷键（留空清除）。
- 点击或按全局快捷键播放一次，再次触发从头播放；其他应用在前台时也能触发。
- 快捷键冲突或无效时保留原有设置。
- 支持 BASS/BASSmix 及已安装的解码扩展；已验证 WAV、AIFF、MP3、OGG、MOD。额外 x64 解码 DLL 放到 `signal_switch/bass_plugins/` 后重启应用。
- 音效文件本身不嵌入工程，工程只保存路径和快捷键；打开工程不会自动播放。

## 峰值电平表

- 按版本有 1/2/6/8 个输入，没有输出端口；请从信号分支接入，不要串联在链路中。
- 各声道独立显示；横向数值在条右侧，纵向数值在条下方；无信号为 −∞。
- 显示范围 -72 至 +12 dBFS。
- 右键可切换水平/垂直方向。

## 增益旋钮

- 一个旋钮同时控制该节点的全部声道。
- 默认范围 -72 至 +12 dB；右键「增益范围…」可修改最小值和最大值。
- 鼠标穿透状态下，Alt+左键可打开「增益」数值输入框。

## 分析表盘

全部是输入测量节点，不改变源音频；设置统一位于组件右键菜单，表盘表面不放模式切换或设置按钮。

- 示波器：每声道独立颜色；综合模式叠加波形，分声道模式独立分区。
- 声谱图：彩色时间/频率/能量图，右键切换线性/对数和综合/分声道。
- 频谱直方图、频谱曲线图：右键切换综合/分声道。综合频谱及声谱图按声道功率平均，反相不会互相抵消。
- 极坐标图：展示声道方位和 RMS 能量；L/R ±30°、C 0°、Ls/Rs ±110°、后环绕 ±150°，Mono 正前方。LFE 在中心单独标注，不是立体声相位矢量图。

## 响度表组

- 四种输入布局都计算整体广播标准值，复用 Meterbridge 的 common 响度引擎、布局权重和 True Peak 算法。
- 右键切换数字/电平表模式、选择 Meterbridge 内置或自定义响度预设。数字模式复用 Meterbridge 公共数字卡片，包含指标标签、大号数值和单位及对应主题配色。
- 电平模式的垂直表条水平排成一整排，每个已选指标一列，数值在条外下方。不同参考线标记目标、上界和峰值上限，带名称和值；预设只改变参考，不改变测量算法。
- 右键「指标显示」默认勾选 M/S/I/LRA/dBTP；可另选 Sample Peak、RMS、LFE Peak。隐藏指标不影响计算或 CSV。
- 自动读取 Meterbridge 全局静音阈值与时长；达到静音时长后，下一段有声开始时自动重置，无需手动操作。
- 右键勾选「保存 CSV 记录」，默认关闭。默认复用全局记录目录；「CSV 设置…」可改用独立目录。全局未配置时需设置目录，状态提示可在组件 tooltip 查看。
- 测量和 CSV 在面板隐藏后仍继续；移除节点才停止。CSV 格式和记录节奏复用 Meterbridge。

## 保存

- 工程保存面板布局、窗口大小和位置、分组、互斥关系、颜色、尺寸、控件透明度、穿透状态和锁定状态。
- 每个节点的开关状态、音效路径/快捷键、增益范围、表盘模式、响度预设、指标显示与 CSV 设置等随节点设置保存。
- 打开工程不会自动播放音效。

## 注意

- 开关是块边界硬切，切换瞬间可能有轻微瞬态。
- 互斥切换允许短暂全关，不保证采样级无缝。
- 同一音高、同一 MIDI 通道的多个来源合流后无法再区分。

公共 UI 控件使用主题 Token 和全局 FPS；算法放在 common。组件规范与开发指南见主仓库 [Control Deck 规范](https://github.com/AI-Hobbyist/WinJACKNexus/blob/broadcast-system/Docs/ControlDeck/规范.md) 和 [组件开发指南](https://github.com/AI-Hobbyist/WinJACKNexus/blob/broadcast-system/Docs/ControlDeck/组件开发指南.md)。

## 分区排列

数字模式响度卡片及多声道示波器、声谱图、频谱曲线和频谱直方图支持右键选择垂直、水平或自定义行列，默认垂直排列。多声道图表在分声道模式下应用排列。自定义行列各为 1–8；格数不足时自动增加行数，保证所有指标/声道可见。排列随节点工程设置保存。响度电平表模式仍保持单排垂直表条。频谱直方图以 64 个更粗的实心频带柱显示，common 按各频带最大功率汇总，避免窄带峰值被漏过。

频谱曲线右键显示模式另提供“彩色声道叠加”：同一坐标区绘制各声道独立颜色曲线和声道图例。综合功率平均、分声道、彩色叠加三种模式均可保存；叠加不改变输入或分析算法。综合/叠加使用完整单区画布，自定义行列仅用于分声道分区。

频谱直方图与曲线图的横轴为频率 Hz/kHz、纵轴为 −90 至 0 dBFS；声谱图横轴为相对时间 s、纵轴为频率 Hz/kHz，随线性/对数模式变化。声谱图每 512 个音频样本写入一个历史列，256 列对应的时间跨度由实际采样率计算，与 UI FPS 无关。多声道分区使用独立卡片边界、背景及声道标签。横轴和纵轴分别根据本分区的可用空间自动隐藏/恢复，不同时强制隐藏；隐藏坐标轴不停止分析或改变数据。

新建多声道图表（电平表除外）默认综合模式，工程恢复保留已保存模式。声谱图默认 Rainbow 固定彩虹色板；仅 Custom 使用 floor/mid/hot 和 analysis-spectrum-violet/cyan/green/red 公共 Theme Token。

声谱图右键光谱预设为 Rainbow（默认）、Fire、Blue Cyan、Grayscale、Custom。前四个使用 common/SpectrogramPalette.hpp 中的固定 LUT 数据，不读取主题光谱颜色；只有 Custom 从公共主题色阶构造 LUT。预设序号 0–4 保存为节点 JSON 的 spectrogramPalette，旧工程缺省为 Rainbow。切换色板清空旧光谱历史，避免混用颜色。坐标、文字和卡片仍由常规 UI 主题控制。

固定 Rainbow、Fire、Blue Cyan 的 LUT 色阶按用户提供的参考色带均匀采样；Grayscale 为黑到白。Rainbow 低能量为蓝紫、高能量为橙红；Fire 为黑紫到黄白；Blue Cyan 为深蓝到青白。固定色板不随 UI 主题改变。

声谱图右侧显示共享的强度色带和 与电平表相同的 −72/−48/−24/−12/0/+12 dBFS 刻度，低能量在下、高能量在上；色带随所选光谱预设实时变化，多声道分区共用该强度标尺。空间不足时隐藏色带以保留图形，横纵坐标轴仍各自独立判断是否显示。

声谱强度标尺范围为 −72 至 +12 dBFS，复用公共 drawMeterScale；颜色只在 −72 至 0 dBFS 变化，0 dBFS 及以上一律使用所选色带最高点。common 的 spectrogramColorAmount 统一执行该饱和映射。

声谱图标题旁在强度超过 0 dBFS 时显示“超限 +X.X dB”，默认红色，使用公共 Token analysis-overload-text；恢复正常后自动隐藏。超限数值按当前显示模式的最高频谱格计算：综合模式先按声道功率平均，分声道模式取各声道最高值。公共 AudioAnalysisWidget::overloadDb() 提供这一实时只读值，common analysisOverloadDb 复用相同聚合算法。
