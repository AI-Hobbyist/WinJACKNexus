# Control Deck 规范

## 节点与目录

所有节点保留 JACK/VIRT 双模式。表盘节点仅有音频输入，不输出、不改变被测音频。布局固定为 Mono、Stereo、5.1、7.1；顺序 L、R、C、LFE、Ls、Rs、Lrb、Rrb，Mono 使用 MONO。

运行目录按功能分层：`nodes/control_deck/routing/<版本>/`、`playback/sound/`、`gain/<版本>/`、`meters/peak/<版本>/`、`meters/loudness/<版本>/`、`analysis/{oscilloscope,spectrogram,polar,spectrum_bars,spectrum_curve}/<版本>/`。节点库对应 Control Deck 下的功能子分类与子子分类。旧模块路径自动迁移到新目录，覆盖包遗留 DLL 不重复列出。模块文件名、项目节点身份和现有音频端口名保持兼容。

## 电平表

保留原单声道，新增 Stereo/5.1/7.1。逐声道独立峰值。横向读数在条右侧，纵向在条下方。方向设置保存到工程；无信号显示 −∞。全部使用公共 FxLevelMeterWidget。

## 新表盘

五类表盘均提供单声道、立体声、5.1、7.1 独立节点，绘图控件放入公共 UI 库，由 Control Deck 组合。公共控件复用 Theme Token、系统字体及全局 30/60/120 FPS。没有业务硬编码颜色、样式或独立刷新频率。

- 示波器：每声道一种主题颜色；综合模式叠加全部声道波形，分声道模式使用独立分区，幅度刻度一致。
- 声谱图：彩色时间/频率/能量图；频率支持线性、对数。综合模式按各声道功率平均，避免反相信号互相抵消；分声道模式分别显示。显示窗口和队列有界。颜色以公共主题色阶表达能量。
- 频谱直方图与频谱曲线图：复用 common 的 Hann 窗 FFT 与功率平均；均支持综合/分声道，综合模式按功率平均，不按波形相加。
- 极坐标图：声道方位和 RMS 能量分布，并非立体声相位矢量图。正前方为 0°；L/R 为 −30°/+30°，C 为 0°，Ls/Rs 为 −110°/+110°，Lrb/Rrb 为 −150°/+150°；Mono 位于正前方。LFE 不假定声学方位，单独在中心标注。

模式设置保存到节点工程状态，改变模式不改变节点/端口身份。恢复和重新打开 Control Deck 后保持模式。新增选项使用公共控件和既有国际化机制。

## 实时与验证边界

音频回调仅向预分配有界 SPSC 队列写入样本，无 FFT、绘图、阻塞锁、堆分配或网络。队列满时丢弃分析数据，不等待音频线程。FFT、RMS、波形缓存、声谱图历史在非实时侧处理；移除节点后释放控件和样本所有权；关闭面板不停止响度后台或 CSV。采样率变化清空过期分析窗口。

自动验证使用离线模块/VIRT 回调或明确的离线 JACK 替身；不连接运行中的 JACK。Qt 验证只能使用可见 Windows 实窗和系统字体，禁止 offscreen。人工听音、实机与安装验收默认 SKIPPED（用户指令），不冒充通过。

## 响度表组

提供单声道、立体声、5.1、7.1 输入版本。所有版本显示按对应声道权重计算的整体广播响度，不计算“每声道 LUFS”。复用 common 的 LoudnessEngine、MeterChannelLayout 和 SilenceResetController；K 加权、声道权重、LFE 与 True Peak 处理沿用 Meterbridge。

数字/电平表模式可切换。数字模式直接复用 Meterbridge 的公共 MetricReadout 数字卡片：指标标签、大号数值和独立单位，沿用指标主题配色。右键“指标显示”默认 M/S/I/LRA/dBTP，可另选 Sample Peak、RMS、LFE Peak。显示选择不改变计算或 CSV 内容，所有选择保存到工程。

电平表模式为多个水平排列的垂直表条，全部已选指标排在同一行，每个指标一列，标签在上方、读数在条外下方。

内置与自定义响度预设复用 Meterbridge 的 preset catalog 与 `lufs_presets` 文件。预设只定义参考，不改变测量算法。目标值为虚线，上界为点线，True Peak 最大值为点划线；各有公共 Theme Token 和文字标注。缺失自定义预设时保留 ID，不伪造参考值。

自动静音重置直接读取 WinJACKNexus/Meterbridge 全局 silenceThresholdDbfs、silenceDurationSeconds，沿用现有控制器语义：持续静音达到时长后进入待重置状态，下一段有声开始前重置。无需手动操作。采样率变动或队列数据不连续也重启测量，不把丢失数据拼接为连续 Integrated 值。

右键勾选“保存 CSV 记录”，默认复用全局 logRootDirectory。右键 CSV 设置可关闭复用，填写/选择独立目录；全局未配置时明确报告未配置，不写入任意回退目录。复用 Meterbridge 的 MeterCsvWriter、10 Hz 记录节奏及 CSV 格式。后台测量和 CSV 不依赖面板可见；移除节点时停止后台并关闭文件。音频回调不读设置、不写文件。

互斥与独立关系选项仅显示在信号开关按钮右键菜单；声源、增益、电平、分析和响度等组件不显示，混合选择也不显示。普通分组不受影响。

所有模式、频率刻度、响度预设等设置统一通过组件右键菜单提供，表盘不显示设置下拉框或按钮。显示区域只包含图形、图例/单位、必要指标与读数。

## 分区排列

数字模式响度卡片及多声道示波器、声谱图、频谱曲线和频谱直方图支持右键选择垂直、水平或自定义行列，默认垂直排列。多声道图表在分声道模式下应用排列。自定义行列各为 1–8；格数不足时自动增加行数，保证所有指标/声道可见。排列随节点工程设置保存。响度电平表模式仍保持单排垂直表条。频谱直方图以 64 个更粗的实心频带柱显示，common 按各频带最大功率汇总，避免窄带峰值被漏过。

频谱曲线右键显示模式另提供“彩色声道叠加”：同一坐标区绘制各声道独立颜色曲线和声道图例。综合功率平均、分声道、彩色叠加三种模式均可保存；叠加不改变输入或分析算法。综合/叠加使用完整单区画布，自定义行列仅用于分声道分区。

频谱直方图与曲线图的横轴为频率 Hz/kHz、纵轴为 −90 至 0 dBFS；声谱图横轴为相对时间 s、纵轴为频率 Hz/kHz，随线性/对数模式变化。声谱图每 512 个音频样本写入一个历史列，256 列对应的时间跨度由实际采样率计算，与 UI FPS 无关。多声道分区使用独立卡片边界、背景及声道标签。横轴和纵轴分别根据本分区的可用空间自动隐藏/恢复，不同时强制隐藏；隐藏坐标轴不停止分析或改变数据。

新建多声道图表（电平表除外）默认综合模式，工程恢复保留已保存模式。声谱图默认 Rainbow 固定彩虹色板；仅 Custom 使用 floor/mid/hot 和 analysis-spectrum-violet/cyan/green/red 公共 Theme Token。

声谱图右键光谱预设为 Rainbow（默认）、Fire、Blue Cyan、Grayscale、Custom。前四个使用 common/SpectrogramPalette.hpp 中的固定 LUT 数据，不读取主题光谱颜色；只有 Custom 从公共主题色阶构造 LUT。预设序号 0–4 保存为节点 JSON 的 spectrogramPalette，旧工程缺省为 Rainbow。切换色板清空旧光谱历史，避免混用颜色。坐标、文字和卡片仍由常规 UI 主题控制。

固定 Rainbow、Fire、Blue Cyan 的 LUT 色阶按用户提供的参考色带均匀采样；Grayscale 为黑到白。Rainbow 低能量为蓝紫、高能量为橙红；Fire 为黑紫到黄白；Blue Cyan 为深蓝到青白。固定色板不随 UI 主题改变。

声谱图右侧显示共享的强度色带和 与电平表相同的 −72/−48/−24/−12/0/+12 dBFS 刻度，低能量在下、高能量在上；色带随所选光谱预设实时变化，多声道分区共用该强度标尺。空间不足时隐藏色带以保留图形，横纵坐标轴仍各自独立判断是否显示。

声谱强度标尺范围为 −72 至 +12 dBFS，复用公共 drawMeterScale；颜色只在 −72 至 0 dBFS 变化，0 dBFS 及以上一律使用所选色带最高点。common 的 spectrogramColorAmount 统一执行该饱和映射。

声谱图标题旁在强度超过 0 dBFS 时显示“超限 +X.X dB”，默认红色，使用公共 Token analysis-overload-text；恢复正常后自动隐藏。超限数值按当前显示模式的最高频谱格计算：综合模式先按声道功率平均，分声道模式取各声道最高值。公共 AudioAnalysisWidget::overloadDb() 提供这一实时只读值，common analysisOverloadDb 复用相同聚合算法。
