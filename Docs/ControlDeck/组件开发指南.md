# Control Deck 组件开发指南

## 模块边界

Control Deck 节点负责固定端口、实时数据采集和工程状态；`control_deck.dll` 的 Service 管理节点身份、卡片及后台测量；公共 `ui.dll` 提供绘图控件。算法放在 `src/common`，业务窗口只组合公共控件，不复制 DSP 或 Meterbridge 实现。响度数字模式直接组合 Meterbridge 使用的公共 `MetricReadout`，复用其标签、大号数字、单位与卡片绘制；指标强调色引用 `meter-bridge/chart-series-*-stroke` 既有主题 Token。

新增组件先确认是否能复用现有公共控件。分析组件使用 `AudioAnalysisWidget`，峰值表使用 `FxLevelMeterWidget`。不要在节点窗口添加局部 QSS、固定颜色或独立字体。

## 新增固定布局组件

1. 在 `src/control_deck/CMakeLists.txt` 登记 kind、通道数、控制类型、显示名和功能分类。固定版本为 Mono、Stereo、5.1、7.1；环绕声顺序 L/R/C/LFE/Ls/Rs/Lrb/Rrb。
2. 在 `NodePaths.hpp` 维护运行目录映射，DLL 和自己的 `locate` 位于同一目录。节点库使用 `Control Deck / 功能 / 类型`，宿主生成多级分类。
3. 为每个模块提供独立 module ID、i18n domain 和四语言 catalog，复用 Node i18n v2；不要让多个 DLL 共用可冲突的模块身份。
4. 在 `Module.cpp` 接入 JACK 和 VIRT 回调、输入端口及状态保存。分析和测量节点仅输入，不创建透传输出。保留既有 kind、稳定端口 ID 和 DLL 文件名。
5. 在 Service 注册组件数据，在 `ControlDeckControls.cpp` 组合公共控件；设置全部放入 `ControlDeckLayout.cpp` 的组件右键菜单。表盘表面不放模式切换、预设或设置按钮。

## 实时数据与算法

`Common::AnalysisCapture` 具有预分配 16384 帧 SPSC 队列，每帧最多八声道及采样率。音频线程调用 `push`，只能有一个生产者和一个消费者。队列满时丢弃剩余分析帧并递增 revision，不阻塞音频。FFT、设置读取、锁、文件操作和绘图均不得进入音频回调。

普通表盘由可见的公共 UI 控件消费；隐藏时停止 UI 刷新。再次显示或采样率变化时清理不连续窗口。响度由 `LoudnessSession` 独占消费，UI 只读快照，因此关闭面板后测量和 CSV 仍继续。

优先复用 common 的算法。当前波形 RMS、1024 点 Hann 窗 FFT 和跨声道功率平均位于 `ControlDeckAnalysis.hpp`。综合频谱按功率平均，不能先相加波形以免反相抵消。极坐标图复用 `MixerPolarCurve`，LFE 不分配方向。

响度复用 `LoudnessEngine`、`MeterChannelLayout`、`SilenceResetController`。参考预设复用 Meterbridge 内置 catalog 和自定义预设存储；记录复用 `MeterCsvWriter`，不得复制 CSV 格式或另造计算引擎。静音阈值、时长和默认记录目录读取 Meterbridge 全局设置。布局权重、LFE 排除和 True Peak 语义由 common 决定。

## 公共绘图 API 与主题

```cpp
auto capture = std::make_shared<Common::AnalysisCapture>(
    Common::AnalysisKind::spectrogram, 2);
auto *plot = new UI::AudioAnalysisWidget(capture, parent, nodeDomain);
```

`AudioAnalysisWidget` 使用 PImpl；构造参数是共享采集源、父控件、国际化域。`rmsLevels()`、`dominantFrequency(channel)` 和 `loudnessSnapshot()` 提供当前显示数据。一个采集源只能连接一个分析消费者；响度消费者固定为后台会话。数据源的共享所有权避免节点移除时悬挂 GUI 事件。

颜色从公共 Theme Token 解析：

| Token | 用途 |
| --- | --- |
| `analysis-channel-1` … `analysis-channel-8` | 各声道波形、曲线、方位和图例 |
| `analysis-spectrum-floor/mid/hot` | 声谱图和频谱直方图的能量色阶 |
| `analysis-reference-target/upper/peak` | 响度目标、上界及 True Peak 参考线 |
| `surface-panel/raised`、`text-primary`、`border-normal`、`accent-primary` | 表盘表面、文字、网格和普通电平条 |

新增主题属性先登记 `Docs/Theme-v1-Registry.json` 和 `Docs/Theme-v1-Defaults.css`，由公共 UI 引用。字体继承系统/应用设置，间距取 Qt style 指标；刷新统一 `bindRefreshTimer`，服从全局 30/60/120 FPS。自绘曲线使用 `Qt::NoBrush`，填充独立绘制。

## 状态与右键菜单

模式、频率刻度、响度预设 ID、指标掩码和 CSV 设置保存到节点 JSON，再由既有工程 Base64 保存。恢复状态不得切换端口身份。显示指标掩码只改变可见内容，不能停止隐藏指标计算或改变 CSV 内容。

响度电平表模式将所有可见指标的垂直表条水平排列为一整排，读数位于条外下方。响度默认显示 M/S/I/LRA/dBTP，其余指标默认关闭；数字/电平模式、指标子菜单、预设和 CSV 均由右键菜单设置。互斥/独立关系仅在信号开关按钮菜单显示；其他组件及混合选择隐藏这两项。

## 验证与交付

完成修改后只在现有 `build` 构建必要 Release 目标。构建、测试、打包前台运行，输出经 `Tee-Object` 保存并立即检查退出码。离线测试覆盖模块端口、真实 VIRT 回调、算法结果、保存恢复、菜单行为、隐藏记录及旧路径迁移，不依赖运行中的 JACK。

Qt 测试使用 Windows 可见实窗和系统字体，等待稳定后截图；禁止 offscreen。每批窗口和菜单显示总数不超过 100。人工听音、安装和实机验收按用户指令记录 SKIPPED，不能记 PASS。保持用户应用和音频进程运行。

新增或修改公共导出行为时同步 `Docs/UI-API.md` 和 `Develop/Node/Node-API.md`。最终增量包按清单包含 DLL、对应语言目录及必要依赖；旧目录由宿主迁移与发现去重处理，不删除用户文件。更新规范、Wiki、交接手册并完成阶段提交和推送。
