# Control Deck 增量替换说明

本包为 Windows x64 Release 增量包，适用于现有 WinJACKNexus 安装，不是完整安装包。包含本次必需的 `ui.dll`、`control_deck.dll`、`mod_patchbay.dll`，以及 38 个 Control Deck 节点及各自四语言目录。

1. 正常保存工程并自行退出 WinJACKNexus，再替换文件；不要在音频运行时覆盖 DLL。
2. 备份安装目录中同名文件，将包内文件按相对路径覆盖到主程序目录，例如 `D:\Program Files\WinJACKNexus`。
3. 正常启动应用。节点库 Control Deck 下按功能分类；通过快捷栏打开控制面板。

旧 `nodes/signal_switch/` 及平铺 `nodes/control_deck/<kind>/` 路径由宿主自动映射到新功能目录，旧副本不重复显示。无需删除用户目录或重连原有 Control Deck 端口；显式保存工程才记录新路径。三个根目录 DLL 需要一起更新。

峰值表提供单声道/立体声/5.1/7.1，读数在条外。示波器、声谱图、极坐标、频谱直方图、频谱曲线和响度表组均提供四种输入布局。分析节点仅输入，连接音频分支即可。

所有模式和设置位于组件右键菜单。响度数字模式复用 Meterbridge 数字卡片；电平模式是水平排列的一整排垂直表条。指标默认 M/S/I/LRA/dBTP。静音重置使用 Meterbridge 全局阈值/时长，CSV 默认关闭，勾选后默认使用全局目录，也可设置独立目录。隐藏面板不停止响度测量或 CSV。

数字卡片与多声道分区默认垂直排列，右键可选择水平排列或自定义行列。宽度/高度可通过既有右键菜单调整；行列容量不足时自动增加行数。频谱直方图使用加粗的实心频带柱。

包内 `manifest.json` 记录源码检查点、逐文件大小及 SHA-256；旁附 `.zip.sha256` 为归档校验。保留旧归档，按本包清单覆盖即可。

自动验证覆盖离线真实模块回调、Windows 可见窗口、设置保存恢复、菜单、分类迁移、静音重置和后台记录。未执行真实 JACK/硬件听音；人工安装和实机验收已跳过（用户指令），不记为通过。没有停止或启动用户应用，也没有自动覆盖安装目录。
