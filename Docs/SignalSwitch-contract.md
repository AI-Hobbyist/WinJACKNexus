# Signal Switch 内部合同

S1，2026-10-19。实现范围以根目录 Signal Switch 计划书为准。

## 信号语义

新节点默认关闭。音频在块边界硬切：开启逐通道单位增益复制，关闭写零，不改连线。MIDI 开启保留事件及帧偏移，关闭清理实际透传的活动音符和延音后阻断；清理完成前不重新开启，不重放关闭期间输入。切换非零音频可能产生瞬态；同音高、同通道多源 MIDI 合流不保证接收端区分来源。

互斥允许全部关闭，跨图也适用。控制侧先关旧成员，处理侧完成该块及 MIDI 清理并确认后才开新成员，允许全关闭间隙，不承诺采样级同时切换。停止的处理实例由停止生命周期确认静音，无需等待不存在的回调；重新准备时读取最终目标。UI 显示目标状态与等待交接状态，不能将目标当成已生效确认。

## 工程状态

`signalSwitchStateBase64` 为 UTF-8 JSON 的标准 Base64 编码，JSON `version` 为 1。状态包括 cards、groups、exclusive、locked、grid、gridX、gridY、window；窗口包含展开 geometry、frameless、topmost、autoHide、opacity、screen、edge。geometry 为逻辑像素 `[x,y,width,height]`。卡片存绝对坐标，组拖动对成员应用同一偏移；这与组锚点加局部坐标等价，避免双份坐标漂移。

卡片 ID 使用工程稳定节点实例 ID；不复制节点名称及通断的权威状态。通断放节点已有 `settingsBase64` 中。组 ID、互斥关系 ID 独立，成员各自最多归属一个组及一个互斥集合。移除节点清理两类引用；互斥不足两成员时解散，空布局组删除，单成员布局组保留。

反序列化完整校验后替换状态，损坏 Base64、无效 JSON、未知版本、无效几何或重叠关系拒绝且保留当前状态。旧工程没有主状态字段时采用默认值。未加载节点的工程身份记录由宿主保留，不因窗口没有活动实例而丢弃预设。切换工程必须替换全部窗口设置，包括位置和尺寸。

## 边界

`State` 为 GUI 线程值模型，仅负责布局、关系目标计算及序列化。节点拥有实时处理状态；服务拥有实例注册、关系命令与窗口。处理线程不得读取 Qt 容器、分配、加锁或调用 UI。五个节点 DLL 通过程序同级的单一主模块共享控制服务，不能各自复制全局注册表。Node v4 ABI 不变。

## 验证范围

S1 离线测试覆盖关系冲突原子性、独立开关、全部关闭、分组与关系独立、删除引用、网格、全部预设往返及无效状态拒绝。S2 验证实时处理和节点 ABI；S3 至 S5 才验证宿主、实窗及发行，不用 S1 模型结果声称真实 JACK 信号链已经验证。
