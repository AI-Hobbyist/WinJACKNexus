# Signal Switch 内部合同

S1，2026-10-19。实现范围以根目录 Signal Switch 计划书为准。

## 信号语义

新节点默认启用，音频和 MIDI 默认直通；此为 2026-10-20 用户要求，替代 S1/S2 历史基线的默认关闭。工程重开恢复已保存的启用或关闭状态。音频在块边界硬切：开启逐通道单位增益复制，关闭写零，不改连线。MIDI 开启保留事件及帧偏移，关闭清理实际透传的活动音符和延音后阻断；清理完成前不重新开启，不重放关闭期间输入。切换非零音频可能产生瞬态；同音高、同通道多源 MIDI 合流不保证接收端区分来源。

互斥允许全部关闭，跨图也适用。控制侧先关旧成员，处理侧完成该块及 MIDI 清理并确认后才开新成员，允许全关闭间隙，不承诺采样级同时切换。停止的处理实例由停止生命周期确认静音，无需等待不存在的回调；重新准备时读取最终目标。UI 显示目标状态与等待交接状态，不能将目标当成已生效确认。

## 工程状态

`signalSwitchStateBase64` 为 UTF-8 JSON 的标准 Base64 编码，JSON `version` 为 1。状态包括 cards、groups、exclusive、locked、grid、gridX、gridY、window；window 包含编辑器 geometry、clickThrough、按钮 opacity、screen、scroll 和 overlayOrigin。geometry 为逻辑像素 `[x,y,width,height]`；两种位置为 `[x,y]`。卡片存画布绝对坐标，组拖动对成员应用同一偏移；这与组锚点加局部坐标等价，避免双份坐标漂移。

锁定隐藏编辑器背景，仅将已排列的按钮原位呈现在其他普通应用窗口前。overlayOrigin 为画布坐标原点映射的屏幕位置，保持锁定前布局；解锁回编辑器。取消无边框及贴边隐藏设置，不保留其运行路径。透明度仅作用按钮。穿透仅用于锁定展示，Alt＋左键命中按钮时只切换该按钮；快捷栏始终提供锁定、解锁、穿透和打开编辑器入口。此为 S1 之后的用户方向调整，原 S1 日志仅证明当时基线；更新后状态的往返由 S2 重新验证。

卡片 ID 使用节点 settings 中持久化的 switchId，为工程稳定的逻辑实例 ID；不使用可能随 JACK 客户端重建变化的物理客户端名定位按钮。图中别名通过宿主同步，节点 settings 的 displayName 保留显示名称。通断放节点已有 `settingsBase64` 中。组 ID、互斥关系 ID 独立，成员各自最多归属一个组及一个互斥集合。移除节点清理两类引用；互斥不足两成员时解散，空布局组删除，单成员布局组保留。

S5 在节点 settings 中增加可选布尔值 `customName`，区分用户名称与可翻译的默认名称。默认值随各节点的独立 i18n domain 热切换，用户名称及组名保持原样；旧记录缺少此字段时，以 displayName 是否不同于原 English 型号名判断。新增字段不改变 Node v4 或已有可选 i18n/theme API 签名。5.1、7.1 的模块描述符使用 `5-1`、`7-1` 稳定标识，磁盘目录和 DLL 文件名继续使用 `5_1`、`7_1`。

反序列化完整校验后替换状态，损坏 Base64、无效 JSON、未知版本、无效几何或重叠关系拒绝且保留当前状态。旧工程没有主状态字段时采用默认值。未加载节点的工程身份记录由宿主保留，不因窗口没有活动实例而丢弃预设。切换工程必须替换全部窗口设置，包括位置和尺寸。

## 边界

`State` 为 GUI 线程值模型，仅负责布局、关系目标计算及序列化。节点拥有实时处理状态；服务拥有实例注册、关系命令与窗口。处理线程不得读取 Qt 容器、分配、加锁或调用 UI。五个节点 DLL 通过程序同级的单一主模块共享控制服务，不能各自复制全局注册表。Node v4 ABI 不变。

## 验证范围

S1 离线测试覆盖关系冲突原子性、独立开关、全部关闭、分组与关系独立、删除引用、网格、全部预设往返及无效状态拒绝。S2 验证实时处理和节点 ABI；S3 至 S5 才验证宿主、实窗及发行，不用 S1 模型结果声称真实 JACK 信号链已经验证。
