# midi matrix S3 完成记录

状态：实现、Release 定向构建、规定离线模型/DLL 与 100% Windows 实窗验证完成。

- 独立单类型 Midi Tools DLL，16 MIDI_IN_01～16/16 MIDI_OUT_01～16；输入端口行、输出端口列，保留原 MIDI 通道/字节。默认对角线，一对多/多对一按帧、输入端口号、原序号排序。
- 256 位路由通过单生产者控制线程原子快照发布；回调每周期尝试一次一致快照，未完成则沿用旧快照，无等待/分配/文件 I/O/Qt。周期总输入事件上限 4096、帧上限 8192。
- 固定来源/目标/通道/音高计数台账及踏板状态。断路立即在周期边界发送原通道/音高的 Note Off 和 CC64 释放后回收；重复 Note On 保留计数。台账总数 4096、单键255 次，有界超限清音；输出失败留待下周期 CC64/123/120 清理，不允许受影响输出新音符。MIDI 1.0 同通道同音高合流的下游身份歧义仍然存在，没有隐式通道改写。
- 独立顶层矩阵窗口组合公共 ActionButton/TextLabel，无私有颜色/QSS/字体/绘制；显示当前16×16连接，关闭仅隐藏，重开复用同一窗口对象和状态（Qt 原生 HWND 可变化）。独立模块四语言通过 I18n v1 host lifecycle 热切换。
- 公共客户端名称侧栏、固定32端口快照/回滚/部分恢复接缝、实际 client ID、version=1/clientName/routes(256 boolean) 严格原子持久化；改名不清空矩阵。
