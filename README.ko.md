# WinJACKNexus

[简体中文](README.md) · [日本語](README.ja.md) · [English](README.en.md) · [한국어](README.ko.md)

Windows x64용 모듈식 오디오 및 MIDI 라우팅 앱입니다. 그래픽 패치베이에서 JACK 포트를 연결하고 장치, 믹서, 네이티브 효과, VST 호스트와 서브그래프를 조합해 처리 체인을 구성할 수 있습니다.

## 현재 제공 기능

| 기능 | 내용 |
| --- | --- |
| 패치베이 | 오디오/MIDI 연결, 프로젝트 저장 및 복원, 서브그래프 |
| 장치 노드 | WASAPI 입출력, 시스템 MIDI 입출력 |
| 믹서 | 디지털 믹서, 8/16/24채널 Classic Mixer |
| Native Fx | Gate, 31밴드 Graphic EQ, De-Esser, Compressor, Limiter, Delay, Parametric EQ, Reverb |
| 미터 브리지 | 다채널 미터, 기록 그래프, CSV 기록 |
| VST 호스트 | VST3. 로컬 빌드에서는 별도 SDK로 VST2도 지원 |
| MIDI Tools | 채널 분리, 16×16 매트릭스, SF2/SFZ 음원 로딩 |
| 컨트롤 덱 | 신호 스위치, 효과음 버튼, 모노 피크 미터, 다채널 게인 노브 |
| 외관 및 언어 | 테마 토큰과 사용자 테마, 중국어·일본어·영어·한국어 |

## 컨트롤 덱

모든 버전은 메인 그래프와 서브그래프를 지원하며 각각 독립 DLL로 제공됩니다. 노드 자체에는 GUI가 없으며 빠른 실행 바에서 컨트롤 덱을 열어 조작합니다.

| 컨트롤 | 버전 및 동작 |
| --- | --- |
| 신호 스위치 | 모노, 스테레오, 5.1, 7.1, MIDI. 새 노드는 기본적으로 켜져 신호를 통과시킴 |
| 효과음 버튼 | 스테레오 출력만 제공. 클릭 또는 전역 단축키로 한 번 재생하며 다시 누르면 처음부터 재생 |
| 피크 미터 | 모노 패스스루, −72~+12 dBFS. 우클릭으로 가로/세로 전환 |
| 게인 노브 | 모노, 스테레오, 5.1, 7.1. 노브 하나로 해당 노드의 전체 채널을 제어하며 dB 범위 변경 가능 |

- 편집기에서 드래그하여 배치합니다. Ctrl 또는 드래그 영역 선택으로 여러 컨트롤을 선택한 뒤 우클릭 메뉴에서 크기, 색상, 그룹, 자유/격자 정렬을 설정할 수 있습니다. 그룹 이름을 바꾸거나 그룹 전체를 이동할 수 있습니다. 신호 스위치는 상호 배타 또는 독립 동작으로 설정할 수 있습니다.
- 이름은 그래프 노드 이름과 동기화됩니다. 기본 색상은 테마를 상속하며 컨트롤별로 지정할 수도 있습니다.
- 레이아웃을 잠그면 편집기 배경이 숨겨지고 배치된 컨트롤이 기존 위치 그대로 일반 앱 창보다 앞에 표시됩니다. 빠른 실행 메뉴에서 잠금, 잠금 해제, 마우스 통과 및 편집기 열기를 선택할 수 있습니다.
- ‘컨트롤 불투명도’는 컨트롤에만 적용됩니다. 마우스 통과 상태에서는 Alt+왼쪽 클릭으로 조작하며, 게인 노브는 숫자 입력 창을 엽니다.
- 효과음 버튼을 우클릭하여 파일과 전역 단축키를 설정합니다. 다른 앱이 전면에 있어도 작동하며, 단축키가 충돌하면 이전 설정을 유지합니다. 지원 형식은 BASS/BASSmix 및 설치된 호환 디코더에 따라 달라집니다. WAV, AIFF, MP3, OGG, MOD를 검증했습니다. 추가 x64 BASS 디코더 DLL은 `signal_switch/bass_plugins/`에 넣고 앱을 다시 시작하세요.
- 배치, 창 크기와 위치, 그룹, 관계, 색상, 컨트롤 크기, 불투명도, 마우스 통과 및 노드 설정은 프로젝트에 Base64로 저장됩니다. 효과음 경로와 단축키도 저장되지만 오디오 파일은 외부에 남습니다. 프로젝트를 열어도 자동 재생하지 않습니다.

`control_deck.dll`은 실행 파일과 같은 폴더에 둡니다. 기존 프로젝트 호환성을 위해 노드와 번역은 `nodes/signal_switch/`, `signal_switch/locate/` 경로를 유지합니다.

## 다운로드 및 실행

Windows x64, JACK2 및 Microsoft Visual C++ 런타임이 필요합니다. 폴더 구조를 유지해 압축을 풀고 `WinJACKNexus.exe`를 실행하세요. 실제 장치를 연결하기 전에 JACK 설정과 배선을 확인하세요.

GitHub에서 **Actions → Build full Release package → Run workflow**를 선택하면 전체 Release를 수동 빌드합니다. 성공한 실행에서 `WinJACKNexus-Release-x64-VST3` 아티팩트를 받으세요. 전체 앱 ZIP, SHA256, Qt 런타임, 현재의 모든 모듈과 `prerequisites/` 안의 JACK2 및 VC++ x64/x86 설치 파일을 포함합니다. 먼저 이 런타임들을 설치하세요. 이 Action은 VST2를 끄고 VST3를 유지합니다. 첫 클라우드 빌드의 실제 결과는 Actions에서 확인해야 합니다.

증분 업데이트 패키지에는 일치하는 기존 버전이 필요합니다. 편한 시점에 직접 앱을 종료하고 백업한 뒤 덮어쓰고 다시 실행하세요. 오디오가 동작하는 동안 DLL을 교체하지 마세요. 증분 패키지는 전체 배포판과 다릅니다.

## 완료 상태 및 예고

컨트롤 덱의 스위치, 효과음, 피크 미터, 네 종류의 게인 노브, 배치 조작 및 프로젝트 복원을 구현했습니다. Release 빌드, 오프라인 처리 및 실제 Windows 창 자동 검증을 통과했으며 다른 프로세스가 전면일 때의 효과음 단축키와 4개 언어 표시도 확인했습니다. 실제 장치, 실제 JACK 연결, 설치 및 수동 인수 검증은 아직 수행하지 않았습니다.

**예고:** DAW Bridge, Carla 연동 및 미완성 메인 세션 오디오 장치 관리 흐름은 계획 또는 개발 중입니다. 현재 제공되는 완료 기능에 포함되지 않습니다.
