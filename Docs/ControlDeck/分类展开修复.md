# Control Deck 分类折叠后展开卡死修复

日期：2026-11-07。范围仅为分类树的辅助功能行缓存同步。

现场 GUI 线程两次采样均位于 Windows UI Automation/COM 调用链；未终止用户进程，未暂停音频线程。安装目录的 41 个交付 DLL 与上一增量包一致，排除了漏替换文件。

离线真实 Windows 窗口回归启用辅助功能并读取树行缓存。修复前折叠 Control Deck 后，辅助功能第 13 行的 Analysis 节点反向索引返回 0，测试以退出码 4 失败。Qt 6.10.3 的折叠代码移除可见行后未刷新缓存；Windows UIA 的 NextSibling 根据反向索引继续导航，过期缓存可导致导航循环。参考 [Qt 树折叠实现](https://github.com/qt/qtbase/blob/v6.10.3/src/widgets/itemviews/qtreeview.cpp)、[辅助功能树缓存](https://github.com/qt/qtbase/blob/v6.10.3/src/widgets/accessible/itemviews.cpp) 和 [Windows UIA 导航](https://github.com/qt/qtbase/blob/v6.10.3/src/plugins/platforms/windows/uiautomation/qwindowsuiamainprovider.cpp)。

公共 DragTreeWidget 在 collapsed/expanded 信号中同步发送辅助功能 ModelReset，使用 Qt 公共 API 更新缓存。保留动画、拖拽、分类层级和辅助功能，不改音频处理路径，也不禁用 UIA。
